# Manuel d'utilisation — QuickPara

*Pour la personne qui gère la boutique. Aucune connaissance technique n'est nécessaire.*

---

## 1. En deux mots : comment ça marche

QuickPara est une **vitrine** sur Internet (quickpara.ma) :

1. Vos clients regardent vos produits et les ajoutent à leur **panier**.
2. Quand ils ont fini, ils appuient sur **« Commander sur WhatsApp »**.
3. WhatsApp s'ouvre avec un **message déjà écrit** (produits, quantités, total, nom, ville) qu'ils vous envoient.
4. **Vous recevez ce message sur votre WhatsApp Business**, vous confirmez la disponibilité et le prix, et vous organisez la livraison avec eux.

**Il n'y a pas de paiement sur le site et pas de gestion de stock.** Tout se règle par WhatsApp, comme avec un client en boutique.

Vos clients peuvent aussi vous écrire librement (question, produit introuvable) avec le bouton vert WhatsApp en bas à droite du site.

Le site a **deux faces** :
- **Le site public** : ce que voient vos clients → `https://quickpara.ma`
- **La console d'administration** : votre « arrière-boutique », où vous gérez vos produits → `https://quickpara.ma/admin`

---

## 2. Ce que vous devez garder précieusement

| Quoi | Pourquoi |
|---|---|
| **Le mot de passe de la console** | Sans lui, impossible de modifier les produits. Notez-le dans un endroit sûr (carnet, gestionnaire de mots de passe). Ne le donnez à personne que vous ne connaissez pas bien. |
| **L'adresse de la console** : `quickpara.ma/admin` | Ajoutez-la à vos favoris, sur ordinateur et téléphone. |
| **Le numéro de la personne qui a installé le site** | Pour toute panne ou mot de passe oublié (voir §12). |

---

## 3. Se connecter à la console

1. Ouvrez votre navigateur (Chrome, Safari, Edge…) sur **quickpara.ma/admin**.
2. Saisissez votre **mot de passe** → bouton **Sign in** (« Se connecter »).
3. Vous arrivez sur la liste de vos produits.

Bon à savoir :
- Vous restez connecté **7 jours** sur cet appareil. Sur un ordinateur partagé, cliquez sur **Sign out** (« Se déconnecter », en haut à droite) quand vous avez fini.
- Après **5 mots de passe faux**, la console se bloque **15 minutes**. Attendez, puis réessayez calmement.
- La console est **en anglais**. Ce manuel donne la traduction de chaque bouton.
- Elle fonctionne aussi sur **téléphone**.

---

## 4. Les trois onglets

En haut de la console :

| Onglet | À quoi il sert |
|---|---|
| **Products** (Produits) | Ajouter, modifier, cacher, supprimer vos produits |
| **Categories** (Catégories) | Les rayons du site : Visage, Bébé, Hygiène… |
| **Settings** (Réglages) | Votre numéro WhatsApp, le nom du magasin, les horaires |

Le lien **View site** (« Voir le site », en haut) ouvre votre site tel que le voient les clients.

---

## 5. Gérer les produits (onglet Products)

### 5.1 Ajouter un produit
1. Cliquez sur **+ New product** (« Nouveau produit »).
2. Remplissez la fenêtre :
   - **Choose photo** (« Choisir une photo ») : facultatif, voir §6.
   - **Name** (Nom) : **obligatoire**. Exemple : *Crème hydratante visage SPF 50*
   - **Brand** (Marque) : facultatif. Exemple : *La Roche-Posay*
   - **Price (MAD)** (Prix en dirhams) : **obligatoire**. Des chiffres seulement. Exemple : `169` ou `89.5`
   - **Category** (Catégorie) : choisissez le rayon dans la liste.
   - **Short description** (Description courte) : une ligne qui aide le client. Exemple : *Protection solaire quotidienne, 50 ml*
   - **Visible on the website** (Visible sur le site) : laissez coché pour que le client le voie tout de suite.
3. Cliquez sur **Save** (« Enregistrer »).

Le produit apparaît sur le site **en quelques secondes** (rechargez la page du site si besoin).

### 5.2 Modifier un produit (prix, nom, photo…)
1. Sur la ligne du produit, cliquez sur le **crayon** ✏️.
2. Changez ce que vous voulez → **Save**.

### 5.3 Cacher un produit (rupture, produit de saison…)
Sur la ligne du produit, utilisez **l'interrupteur vert** :
- **Vert** = visible par les clients.
- **Gris** = caché. Le produit **reste** dans votre console, vous pouvez le réactiver quand vous voulez.

C'est la bonne méthode quand un produit est **en rupture** : cachez-le, puis réactivez-le au réapprovisionnement. Rien à retaper.

### 5.4 Supprimer un produit
Cliquez sur la **corbeille** 🗑️ rouge, puis confirmez. **La suppression est définitive** (photo comprise). En cas de doute, **cachez** plutôt que supprimer.

### 5.5 Retrouver un produit
- Barre de recherche (« Search products… ») : tapez une partie du nom ou de la marque.
- Liste **All categories** : filtre par rayon (la dernière entrée, **Uncategorised**, montre les produits sans catégorie).

---

## 6. Les photos

- Formats acceptés : **JPEG, PNG ou WebP**. Une photo de téléphone convient très bien.
- Pas besoin de la réduire : **la console la redimensionne toute seule**.
- Conseils pour qu'elle soit belle sur le site :
  - **Fond clair et uni**, produit au centre, bonne lumière (près d'une fenêtre, sans flash).
  - Photo **horizontale ou carrée** de préférence.
  - Un seul produit par photo.
- Pour **changer** la photo : modifiez le produit (✏️) → **Choose photo** → **Save**. L'ancienne est supprimée automatiquement.
- Pour **enlever** la photo : modifiez le produit → **Remove photo** → **Save**. Le site affiche alors une icône de la catégorie.
- Un produit **sans photo** s'affiche très bien : c'est une icône colorée.

---

## 7. Les catégories (onglet Categories)

Les catégories sont les boutons de filtre au-dessus des produits sur le site (Visage, Bébé & maman…).

- **Ajouter** : tapez le nom, choisissez une **icône** dans la liste (Face = visage, Baby & mom = bébé, Supplements = compléments, Hygiene = hygiène, First aid = premiers soins, Body & hair = corps et cheveux, Generic = générique), puis **Add** (« Ajouter »).
- **Renommer** ou **changer l'icône** : modifiez directement la ligne, puis **Save**.
- **Supprimer** (corbeille rouge) : les produits de cette catégorie **ne sont pas supprimés** ; ils passent en « Uncategorised » (sans catégorie). Pensez ensuite à les ranger dans un autre rayon.
- Deux catégories ne peuvent pas avoir le même nom.

---

## 8. Les réglages (onglet Settings)

| Champ | Ce qu'il fait |
|---|---|
| **WhatsApp number** | **Le numéro qui reçoit les commandes.** Écrivez-le comme d'habitude (`06 12 34 56 78`) : la console le convertit toute seule. |
| **Store name** (Nom du magasin) | Apparaît au début des messages de commande. |
| **Opening hours** (Horaires) | Affichés en bas du site. Exemple : *Lun–Sam, 9h–20h* |

Cliquez sur **Save settings** (« Enregistrer »).

⚠️ **Si vous changez le numéro WhatsApp**, faites **une commande test** juste après (voir §10) pour être sûr que vos messages arrivent bien chez vous.

---

## 9. Quand une commande arrive (côté WhatsApp)

Le client vous envoie un message de ce style :

> Bonjour QuickPara, je souhaite commander :
> • 2 × Gel nettoyant purifiant (129 MAD) = 258 MAD
> • 1 × Thermomètre digital (79 MAD) = 79 MAD
> Total estimé : 337 MAD
> Nom : Sara — Ville / quartier : Rabat Agdal
> Merci de me confirmer la disponibilité et la livraison.

Votre façon de procéder (suggestion) :

1. **Répondre vite** (le client attend) : « Bonjour Sara, merci pour votre commande ! »
2. **Vérifier que tout est disponible.** Le total est « **estimé** » : c'est à vous de confirmer les prix et d'ajouter les frais de livraison.
3. **Confirmer** : produits, total final, adresse précise, jour et heure de livraison, mode de paiement (à la livraison, virement…).
4. **Livrer**, puis remercier.

Astuce : dans **WhatsApp Business**, vous pouvez enregistrer des **réponses rapides** (par exemple « Bonjour, merci pour votre commande… ») pour gagner du temps. Et utilisez les **étiquettes** (« Nouveau », « À livrer », « Livré ») pour suivre vos commandes.

---

## 10. Votre routine conseillée

**Au quotidien**
- Répondre aux commandes WhatsApp.
- **Cacher** (interrupteur gris) les produits en rupture ; les réactiver à la livraison du fournisseur.

**Une fois par semaine** (5 minutes)
- Ouvrir **quickpara.ma** sur votre téléphone : tout s'affiche ? Les prix sont à jour ?
- Faire **une commande test** : ajoutez un produit, cliquez sur « Commander sur WhatsApp ». Vérifiez que le message arrive bien sur votre WhatsApp Business.

**Quand vous changez un prix** : modifier le produit (✏️), **Save**, puis regarder le site.

---

## 11. Ce que le site ne fait pas (volontairement)

- Pas de **paiement en ligne** : on s'arrange par WhatsApp.
- Pas de **gestion de stock** : c'est vous qui cachez un produit en rupture.
- Pas de **comptes clients**.
- Pas de **calcul des frais de livraison** : vous les annoncez dans votre réponse.

---

## 12. En cas de problème

| Ce que vous voyez | Ce qu'il faut faire |
|---|---|
| **« Wrong password »** | Vérifiez le clavier (majuscules, langue). Après 5 essais, attendez 15 minutes. |
| **J'ai oublié mon mot de passe** | Contactez la personne qui a installé le site : elle peut le remplacer en 5 minutes. Il n'existe pas de bouton « mot de passe oublié » (c'est voulu, pour la sécurité). |
| **Mon produit n'apparaît pas sur le site** | Vérifiez que l'interrupteur est **vert**. Rechargez la page du site (sur téléphone : fermez et rouvrez le navigateur). |
| **La photo ne s'envoie pas** | Utilisez une photo JPEG, PNG ou WebP. Essayez une autre photo ; sinon, enregistrez le produit sans photo et réessayez plus tard. |
| **Le site affiche « Impossible de charger le catalogue »** | Rechargez la page. Si ça dure plus de quelques minutes, prévenez la personne qui gère la technique. |
| **Les commandes arrivent sur un mauvais numéro** | Onglet **Settings** → corrigez **WhatsApp number** → **Save settings** → faites une commande test. |
| **La console me déconnecte** | Normal après 7 jours. Reconnectez-vous. |
| **« Your session expired »** | Même chose : reconnectez-vous. |

**Avant d'appeler à l'aide**, notez : ce que vous faisiez, ce qui s'affichait (une photo d'écran aide beaucoup), et sur quel appareil (téléphone/ordinateur).

---

## 13. Sécurité : les bonnes habitudes

- **Ne donnez jamais** votre mot de passe par message ou par téléphone à quelqu'un qui vous le demande (même s'il prétend travailler pour Cloudflare, WhatsApp ou l'hébergeur).
- Pensez à **vous déconnecter** (Sign out) sur un appareil qui n'est pas le vôtre.
- Si vous pensez que quelqu'un connaît votre mot de passe : prévenez immédiatement la personne qui gère la technique pour le changer.
- Faites régulièrement une **liste de vos produits et prix** (une capture d'écran de la console suffit) : cela sert de petite sauvegarde. La personne qui gère la technique peut aussi faire une sauvegarde complète.

## 14. Les coûts

- Le site (hébergement, base de données, photos) : **gratuit** tant que l'activité reste raisonnable, ce qui est le cas d'une boutique de cette taille.
- Le nom **quickpara.ma** : à **renouveler une fois par an** auprès de votre registrar. **Mettez un rappel dans votre agenda** : si le domaine expire, le site disparaît.
- WhatsApp Business : gratuit.

## 16. Rappel important sur ce que vous vendez

Ce site est conçu pour la **parapharmacie et les produits paramédicaux**. La vente de **médicaments** est réglementée au Maroc et réservée aux pharmaciens autorisés. Si vous avez un doute sur un produit, renseignez-vous auprès d'un pharmacien ou de l'autorité compétente **avant** de le proposer sur le site. Évitez aussi de promettre des effets médicaux dans les descriptions : restez factuel (contenance, usage, type de peau).
